# 실제 폰 테스트 (11/1까지)

배포 주소: https://jaeminlim-max.github.io/DKCCC/ (배포 승인 후)

준비: iPhone(Safari) 1대, Android(Chrome) 1대. 가능하면 학생들이 많이 쓰는 기종으로.

## 1. 공통 (두 폰 모두)
| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 간사용 페이지(`/staff/`) → QR 모음의 홈 QR을 카메라로 찍기 | 홈이 열린다 |
| 2 | 홈을 한 번 연 뒤 비행기 모드 켜고 각 활동 열기 | 모두 열린다 (오프라인) |
| 3 | 오른쪽 위 "어둡게/밝게" 누르기, 다른 페이지로 이동 | 선택한 테마가 유지된다 |
| 4 | 기기 설정을 다크 모드로 바꾸고 처음 열기 | 어두운 화면으로 열린다 |

## 2. 이미지 저장 (가장 중요)
| 페이지 | 할 일 | iPhone 기대 결과 | Android 기대 결과 |
|---|---|---|---|
| 기도 명단 | 이름 2~3개 → "카드 이미지 저장" → 시트의 **사진에 저장 / 공유** → "이미지 저장" | 사진 앱에 카드 이미지 | 공유 시트 또는 다운로드 폴더 |
| 결단 카드 | "카드 이미지 저장" | 위와 같음 | 위와 같음 |

- 버튼으로 안 되면: 시트 안의 이미지를 **길게 눌러** "사진에 저장"이 되는지 확인.
- iPhone에서 "파일로 내려받기"는 사진이 아니라 '파일' 앱에 저장된다 (정상).

## 3. 진동·소리
| 페이지 | 할 일 | iPhone | Android |
|---|---|---|---|
| 죄 목록 ❹ | 종이를 세 번 누르기 | **진동 없음 (iOS Safari는 진동 미지원, 정상)** | 누를 때마다 짧은 진동 |
| 기도 명단 | "눈 감기 시작" → 30초 | 부드러운 알림음 (무음 스위치 켜면 안 날 수 있음 — 확인 필요) | 진동 + 알림음 |
| 과제 낭독 타이머 | 끝까지 기다리기 | 알림음 | 진동 + 알림음 |

## 5. 결단 카드 불러오기
기도 명단에 이름 입력 → 결단 카드 → "기도 명단에서 불러오기" → 이름을 누르면 칸 1에 들어가는지.

## 6. 반응대처법 도표
대답 버튼을 눌러 끝까지 가 보고, "한 단계 뒤로"·"처음부터"·"전체 도표"가 되는지.

## 7. 간증문 제출 → 간사용 조회 (서버 연결 후)
과제 ② → 이름·간증문 → [제출하기] → "제출했어요" 표시 → 간사용 페이지에서 암호 → 목록에 보이는지 → Google 시트에도 한 줄 생겼는지.

## 8. 지우기
각 페이지의 "이 폰에서 지우기" → 새로고침해도 비어 있는지.

## 문제가 생기면
어느 폰(기종·OS 버전), 어느 페이지, 무엇을 눌렀는지, 화면 캡처를 함께 알려 주세요.
